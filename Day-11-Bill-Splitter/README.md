# 🧾 Day 11/75 — Bill Splitter

A simple Bill Splitter built with Python. 🐍

## 💻 What it does

This program calculates the total bill including the tip and splits the amount equally among the given number of people.

## ▶️ How to Run

```bash
python main.py

```
## 📌 Example

```text

Enter bill amount: ₹1000
Number of people: 4
Tip percentage: 10

🧾 BILL SUMMARY
Total: ₹1100.00
Each person pays: ₹275.00
