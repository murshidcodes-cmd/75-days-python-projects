# ⌨️ Day 16/75 — Typing Speed Tester

A simple Typing Speed Tester built with Python. 🐍

## 💻 What it does

This program measures how quickly you can type and calculates your typing speed in WPM.

## ▶️ How to Run

```bash
python main.py

```
