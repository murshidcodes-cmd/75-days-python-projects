# 📱 Day 12/75 — QR Code Generator

A simple QR Code Generator built with Python. 🐍

## 💻 What it does

This program converts text or a URL into a QR code and displays it directly in the terminal.

## ▶️ How to Run

```bash
pip install "qrcode[pil]"
python main.py

```
