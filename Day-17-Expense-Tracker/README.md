# 💰 Day 17/75 — Expense Tracker

A simple Expense Tracker built with Python. 🐍

## 💻 What it does

This program allows you to add expenses, view all expenses, and calculate the total amount spent.

## ▶️ How to Run

```bash
python main.py

```
