# 🎯 Day 20/75 — Number Statistics

A simple Number Statistics program built with Python. 🐍

## 💻 What it does

This program analyzes a list of numbers and calculates the largest number, smallest number, average, and total.

## ▶️ How to Run

```bash
python main.py

```
📌 Example

```text
Enter numbers separated by spaces: 10 25 7 42 18

📊 NUMBER STATISTICS
Largest:  42
Smallest: 7
Average:  20.40
Total:    102
